# Породи тварин — ЛР №4 «Вебформи та елементи керування»

Навчальний проєкт з дисципліни «Клієнтські технології Web-програмування».
Варіант 3 — породи тварин. Виконав: Мудрий Ярослав, КН-43-5.

Без CSS і без JavaScript — лише HTML5.

## Сторінки
- `index.html` — каталог порід
- `details.html` — деталі породи + форма запиту на консультацію (GET)
- `about.html` — про проєкт
- `admin.html` — таблиця порід + форма додавання (GET)
- `admin-edit.html` — форма редагування (GET)

Словник полів моделі: [docs/model-dictionary.md](docs/model-dictionary.md)

> Сторінка адміністрування — навчальна імітація, вона не захищена. Контроль доступу й остаточна перевірка даних мають виконуватися на сервері.
